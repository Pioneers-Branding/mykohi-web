Fix first

  1. Log in to Cloudflare and turn off "I'm Under Attack" mode, or lower the Security Level, under Security → Settings.
  2. Check Security → WAF custom rules for any rule that applies a Managed Challenge to all traffic, and remove or narrow it.
  3. Under Bots, keep verified bots allowed, so Googlebot, Bingbot and AdsBot are never challenged.
  4. Test from a phone on mobile data and with Google Search Console's URL Inspection. The live test must show the real homepage.
  5. Submit the sitemap in Search Console once pages load, and request indexing for the homepage.
  6. Tell us when it's open, and we'll run the full audit (on-page SEO, content, local SEO, speed and privacy).

How it was checked

Passed: Cloudflare DNS and CDN, a valid TLS certificate (Google Trust Services, valid to 23 Jan 2027), and Google Workspace email with SPF and DKIM. Checks made: direct requests to every standard address, response headers, DNS and certificate lookups, a Lighthouse run in real Chrome, and web searches for the domain and practice name, on 15 and 24 Nov 2026. Nothing was done to get around the block.
